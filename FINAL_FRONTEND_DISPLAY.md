### Visual Design:
- **Percentage**: Bold, colored text (green for boosts, red for reductions)
- **(GS)**: Indicates game script adjustment
- **Explanation**: Smaller italic text below percentage
- **Reasoning**: Clear 1-2 sentence explanation of why adjustment was made

### Types of Explanations:

**Game Script (Favorites):**
- "Favorite team likely to run more with lead. Game script reduces receiving opportunities."
- "Favorite team expected to control clock with ground game. Game script boosts rushing volume."
- "Favorite team likely to limit passing with lead. Game script reduces passing attempts."

**Game Script (Underdogs):**
- "Underdog team expected to pass more in catch-up situations. Game script favors receiving stats."
- "Underdog QB expected to throw more in garbage time. Game script increases passing volume."
- "Underdog team likely to abandon run game when trailing. Game script reduces rushing attempts."

**Opportunity-Based:**
- "High target share (25.0%) reduces variance. More predictable performance expected."
- "Low target share (8.0%) increases variance. Less predictable performance expected."

**Matchup-Based:**
- "Adjustment based on opponent matchup vs league average defensive performance."

### User Benefits:
1. **Complete Transparency**: See exactly why each adjustment was made
2. **Educational**: Learn about game script and opportunity factors
3. **Confidence Building**: Understand the reasoning behind projections
4. **Strategic Insights**: Make better betting decisions with context

The system now provides full transparency into the sophisticated adjustment calculations, helping users understand and trust the projections.
